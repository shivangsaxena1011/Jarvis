# Engineering Roadmap — SHIVANI

The phased roadmap guiding the evolution of SHIVANI from personal computer assistant to full autonomous operating layer.

---

## Phase 1 — Foundation (Completed)
- [x] Monorepo architecture & Python 3.12 `uv` dependency setup.
- [x] Three-tier Permission Engine (`SAFE`, `SENSITIVE`, `CRITICAL`).
- [x] Command sandbox & destructive pattern rejection.
- [x] Structured redacting Audit Logger (`audit.jsonl`).
- [x] Extensible LLM Provider layer (Google Gemini, OpenAI, Mock).
- [x] Baseline Tool Registry & Verification system.
- [x] Context manager & Hindi/Hinglish intent normalizer.
- [x] Emergency Stop controller with `"Shivani stop"` abort handling.
- [x] Real-time FastAPI server with WebSocket event streaming.
- [x] Polished futuristic Desktop Web Dashboard.
- [x] Complete automated test suite (100% pass).

---

## Phase 2 — Voice Pipeline
- [ ] Local wake word detection via `openWakeWord` ("Shivani").
- [ ] Low-latency STT integration using `faster-whisper`.
- [ ] Multilingual TTS via `Edge TTS` (calm female Indian voice).
- [ ] Hands-free duplex conversational loop.

---

## Phase 3 — Advanced Computer Agent
- [ ] Native Windows UI automation via Win32 / pywinauto.
- [ ] Advanced visual element detection with local multimodal models.
- [ ] Smooth mouse and keyboard macro replay.
